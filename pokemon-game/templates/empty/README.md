# {{TITLE}}

An empty world: one room and one person. Nothing here is a suggestion.

## Play it
Open `index.html`. Add `?edit=1` to the address to build.

## Build it
- **In the game.** Creator Mode paints the map, places people, writes what they
  say, and plays from wherever you are standing — on a laptop or a phone.
- **In a file.** `story.js` is the whole world as plain data. `npm run build`
  turns it into the game's content files.
- **From other tools.** `node tools/import.js <file>` brings in a map from
  Tiled, a project from RPG Maker MV, or art from Aseprite.

## What to change first
The title and the first room. Then whether anyone else is in it.
